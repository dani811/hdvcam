## Reglas para ampliar

1. Toda función nueva apunta a una fila con fuente concreta de reversing.
2. Guardar muestras de protocolo saneadas en fixtures; separar observación real de datos sintéticos.
3. Añadir tests de codificación/parsing antes de permitir transporte.
4. No activar operaciones de escritura de cámara hasta validar destino, payload y respuesta en un dispositivo autorizado.
5. Cada checkpoint informa lo implementado, probado, parcialmente conocido y desconocido.
